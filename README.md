# TimeBlocker

Що робить:
- додаєш будь-який .exe у список;
- для кожного EXE встановлюєш окремий денний ліміт;
- програма рахує час, поки процес EXE запущений;
- гра може бути у фоні, згорнута або просто висіти — час все одно рахується;
- коли ліміт закінчився, програма примусово закриває EXE;
- якщо спробувати запустити його знову того самого дня, він знову буде закритий;
- о 00:00 ліміти автоматично починаються з нуля наступного дня;
- налаштування зберігаються у limits.json.

ПРИКЛАД:
RobloxPlayerBeta.exe -> 60 хв/день

Запустив Roblox о 18:00 і залишив його відкритим до 19:00:
використано 60 хв.
Після цього Roblox закриється.
Якщо запустити його о 20:00 — він одразу буде закритий.

ЗАПУСК:
1. Потрібен Python 3.
2. Запусти start.bat.
3. Натисни "Додати EXE".
4. Введи назву процесу, наприклад RobloxPlayerBeta.exe.
5. Встанови ліміт.

ВАЖЛИВО:
Це простий користувацький блокувальник. Якщо його повністю закрити,
контроль припиняється. Для надійного блокування навіть після перезапуску
потрібна версія, яка працює як Windows Service і автоматично запускається
разом із Windows.
